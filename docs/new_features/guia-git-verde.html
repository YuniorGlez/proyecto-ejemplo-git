1. ¿Qué es Git y cómo funciona?

Git es como una máquina del tiempo con cámara fotográfica para tu código. En lugar de guardar copias del proyecto llamadas "proyecto-final-v2-definitivo.zip", Git te permite tomar capturas (llamadas commits) de tus archivos de forma organizada y segura.

El ciclo de trabajo en Git consta de tres zonas locales y una zona remota. En nuestra aplicación, puedes visualizar este flujo perfectamente de izquierda a derecha:

1

Directorio de Trabajo

Tu escritorio real. Aquí creas y modificas archivos sin que Git los guarde todavía de forma permanente.

2

Área de Preparación

También llamada Staging Area. La mesa donde ordenas y eliges qué archivos van a entrar en tu foto.

3

Repositorio Local

El álbum de fotos de tu computadora. Al hacer commit, guardas un registro permanente en tu máquina.

4

Repositorio Remoto

La nube (GitHub). Al hacer push, subes tu álbum local para compartirlo con tu equipo o respaldarlo.

2. Los tres comandos mágicos de hoy

Para mover tus archivos a través de estas zonas, utilizas comandos en la terminal:

📥 1. Preparar cambios (Staging)

Usa git add <archivo> (o git add . para todo) para mover tus cambios del Directorio de Trabajo al Área de Preparación. Es como colocar los objetos sobre la mesa antes de tomar la foto.

📷 2. Guardar permanentemente (Commit)

Usa git commit -m "Mensaje explicativo" para tomar la foto. Esto sella los archivos que estaban en el Área de Preparación y les asigna un identificador único (SHA) en tu álbum local.

☁️ 3. Compartir en la nube (Push)

Usa git push origin <rama> para subir tus commits locales al repositorio remoto (GitHub). Esto sincroniza tu trabajo con el servidor.

4. Próximos pasos recomendados

Ahora que los colores son verdes y elegantes, ¡puedes practicar en el simulador! Escribe comandos reales en la consola interactiva como: 

# Inicializa un nuevo repositorio
git init

# Comprueba el estado de tus archivos
git status

# Añade un archivo creado
git add index.html

# Realiza un commit con un mensaje descriptivo
git commit -m "Mi primer guardado interactivo"
